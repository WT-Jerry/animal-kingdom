# 動物王國語音導覽

本機靜態網站。主頁需通行密碼後才能觀看，子頁同樣受保護。

## 本機開啟

```bash
~/Project_Animal_Kingdom/open.sh
```

或：

```bash
cd ~/Project_Animal_Kingdom
python3 -m http.server 8765
```

## 資料夾

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 登入門與主頁 |
| `gate.js` | 通行檢查 |
| `guides/` | 二十六個子頁 |
| `guides/subpage-spec.md` | 子頁定版規範（後續頁照這份做） |
| `guides/media/` | 前言封面與導覽語音 |
